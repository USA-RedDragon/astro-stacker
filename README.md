# astro-stacker

[![coverage](https://raw.githubusercontent.com/USA-RedDragon/astro-stacker/main/.github/badges/coverage.svg)](https://github.com/USA-RedDragon/astro-stacker/actions)

Indexes, scores, previews and stacks astrophotography frames from an S3 bucket, using Siril for calibration and registration.

## Configuration

Settings are read from `config.yaml` in the working directory (see [config.example.yaml](config.example.yaml)), environment variables and command-line flags.
